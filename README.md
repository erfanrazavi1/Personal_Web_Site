## 🌟 About This Project

This is my **personal portfolio website** built to:

- Present myself as a Django backend developer
- Showcase real projects (some private, some public)
- Share tech stack, learning journey, and future goals
- Serve as a clean, fast, and responsive landing page

---

## 🛠️ Tech Stack

| Layer          | Technology                          | Purpose                              |
|----------------|-------------------------------------|--------------------------------------|
| Backend        | Django (Python)                     | Core logic, APIs, admin panel        |
| Frontend       | HTML5, CSS3, JavaScript             | Responsive UI, animations            |
| Styling        | Tailwind CSS / Custom CSS           | Modern, utility-first design         |
| Deployment     | Docker, Docker Compose, Nginx       | Containerization & reverse proxy     |
| CI/CD          | GitHub Actions                      | Automated build & deploy pipeline    |


---

## ✨ Key Features

- Responsive design (mobile-first)
- Dark/Light mode support (if implemented)
- Project showcase section with descriptions & links
- Skills & tech badges
- Contact form / social links
- Smooth scrolling & micro-interactions
- SEO friendly structure
